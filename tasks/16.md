# EXECUÇÃO CONTROLADA — DADOS FICTÍCIOS

## **1. OBJETIVO**

Preparar a execução do seed de demonstração do Sistema de Gestão de Projetos do IGEPPS.

O mecanismo já foi implementado e os testes passaram.

Quero popular exclusivamente o banco local de desenvolvimento para visualizar os projetos fictícios no sistema.

## **2. VERIFICAÇÕES OBRIGATÓRIAS**

Antes de executar qualquer escrita:

1. Confirmar o ambiente NODE_ENV.
2. Confirmar o nome e a localização do banco PostgreSQL.
3. Confirmar que a conexão não aponta para produção ou homologação.
4. Verificar se existem dados previamente cadastrados.
5. Identificar os registros que serão preservados.
6. Confirmar que os usuários fictícios não conflitam com usuários existentes.
7. Verificar se as migrations necessárias já foram aplicadas.
8. Confirmar que não serão disparados e-mails ou integrações externas.

## **3. EXECUÇÃO**

Se todas as verificações forem satisfatórias e o banco for comprovadamente exclusivo de desenvolvimento:

- Executar o seed usando os scripts existentes.
- Utilizar uma senha de demonstração temporária, sem exibi-la em logs ou respostas.
- Não executar comandos de limpeza.
- Não modificar migrations.
- Não alterar autenticação.
- Não criar funcionalidades adicionais.

Se houver qualquer dúvida sobre a segurança do ambiente, NÃO executar o seed. Apresentar o problema e aguardar autorização.

## **4. VALIDAÇÃO**

Após a execução:

1. Confirmar a quantidade de projetos criados.
2. Confirmar a quantidade de usuários fictícios.
3. Verificar fases, tarefas, marcos e membros.
4. Confirmar os cenários de atraso, suspensão e impedimento.
5. Verificar que o usuário de teste PMO foi preservado.
6. Confirmar que os projetos podem ser consultados pelos endpoints existentes.
7. Informar se os dados já podem ser utilizados pelo frontend.

## **5. RESTRIÇÕES**

- Não alterar o frontend.
- Não implementar a RN-001.
- Não disparar notificações.
- Não enviar e-mails.
- Não modificar registros fora do catálogo fictício.
- Não executar exclusões.
- Não conectar serviços institucionais.

Apresente um resumo da execução e dos dados inseridos.
