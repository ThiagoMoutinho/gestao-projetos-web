# IMPLEMENTAÇÃO 02 — LISTAGEM DE PROJETOS

## **1. OBJETIVO**

Implementar a tela de listagem de projetos do Sistema de Gestão de Projetos do IGEPPS, utilizando os dados fictícios já inseridos no PostgreSQL.

A API já possui projetos cadastrados e o endpoint GET /projects foi validado.

Nesta etapa, desenvolver somente a visualização da listagem de projetos.

## **2. INTERFACE**

Utilizar obrigatoriamente os componentes oficiais do shadcn/ui já instalados no projeto.

Preservar:

- Sidebar existente.
- Tipografia e espaçamentos atuais.
- Identidade visual institucional.
- Estrutura de navegação existente.
- Padrões visuais já aprovados.

Não redesenhar o dashboard nem criar um novo layout geral.

Ativar o item Projetos no menu lateral.

## **3. FUNCIONALIDADES**

A tela deverá apresentar:

- Nome do projeto.
- Área, quando disponível na API.
- Situação operacional.
- Responsável principal.
- Gestor, quando disponível.
- Data prevista, quando disponível.
- Percentual de andamento, somente se existir dado confiável na API.

Implementar:

- Listagem com dados reais da API.
- Pesquisa por nome do projeto.
- Filtros pelos campos efetivamente disponíveis.
- Estados de carregamento.
- Estado vazio.
- Tratamento de erros.
- Navegação para detalhes somente se a rota já existir.

Não inventar dados ou indicadores para preencher campos ausentes.

## **4. INTEGRAÇÃO COM A API**

- Reutilizar o cliente HTTP e a autenticação existentes.
- Respeitar permissões de acesso.
- Não utilizar arrays fictícios fixos no frontend.
- Não expor projetos
