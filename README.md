# Regras do Cursor — Sistema de Gestão de Projetos IGEPPS

Copie os três arquivos `.mdc` da pasta `.cursor/rules/` para a pasta `.cursor/rules/` na raiz do workspace aberto no Cursor.

Se o Cursor estiver aberto diretamente na pasta `gestao-projetos-web`, coloque `.cursor/rules/` nessa pasta e verifique se os globs correspondem à estrutura real. As regras de governança também se aplicam ao backend quando a raiz for o workspace completo.

Antes de usar, revise os padrões para conferir compatibilidade com a estrutura e versões instaladas no repositório.

As regras não modificam o código automaticamente. Peça uma auditoria antes de autorizar a refatoração de `eap-panel.tsx`.
